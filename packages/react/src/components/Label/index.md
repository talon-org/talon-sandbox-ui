# Label 表单标签

渲染 `<label>` 元素，带 `tln-field-label` 语义类。通常与 Input / Select 通过 `htmlFor + id` 关联。

## Props

| 属性 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| required | 末尾显示必填星号（*） | `boolean` | — |
| htmlFor | 关联控件的 id | `string` | — |
