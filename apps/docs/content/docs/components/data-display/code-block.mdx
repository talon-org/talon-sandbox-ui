## Overview

`CodeBlock` wraps `<pre><code>` with Talon's monospace token styling and an optional copy button. It is designed for **read-only code display** — startup scripts, configuration snippets, command examples.

### When to use vs Textarea

- Use `CodeBlock` for read-only display of code or structured text.
- Use `Textarea` when the user needs to edit the content.
- Never put code into a `Textarea` as a display-only pattern — it loses scroll semantics and inherits form styling.

## Accessibility

- `copyable` renders a `<button>` with `aria-label="Copy code"` and an `aria-live="polite"` region that announces "Copied" / "Failed" after the clipboard write.
- The `<pre>` element is scrollable — keyboard users can scroll with `Arrow` keys when the element is focused.
- Do not place interactive elements inside `children` — `CodeBlock` renders children inside `<code>` as plain text.
