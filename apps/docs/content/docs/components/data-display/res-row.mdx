## Overview

`ResRow` displays a single resource dimension (CPU, memory, storage) as a label + progress bar + numeric value. It is designed to be stacked in a resource panel alongside other `ResRow` instances.

## Accessibility

- The underlying `ProgressBar` exposes `role="progressbar"` with `aria-valuenow`, `aria-valuemin`, and `aria-valuemax`.
- The label is a sibling element — associate it explicitly via `aria-label` on the `ProgressBar` if standalone usage is required.
