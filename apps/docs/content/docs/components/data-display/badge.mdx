## Overview

`Badge` is a compact inline label for categorical metadata — environment tags, permission levels, plan tiers. `StatusBadge` extends it with a semantic animated dot and predefined status semantics for sandbox lifecycle states.

### When to use

- Use `Badge` for general categorical labels where you pick the color yourself.
- Use `StatusBadge` for sandbox lifecycle states (`running`, `stopped`, `error`, `pending`) — it maps states to the correct semantic color and dot animation automatically.

## StatusBadge

`StatusBadge` maps the four sandbox lifecycle states to the correct semantic color and dot animation. The dot animates for `running` and `pending`; it is static for `stopped` and `error`.

## Accessibility

- `Badge` renders a `<span>` — it is inline text from a screen reader's perspective.
- The animated dot uses `aria-hidden="true"` so it is not announced.
- When a badge communicates status (not just decoration), ensure the surrounding text or an `aria-label` on the parent element conveys the same meaning to screen readers.
