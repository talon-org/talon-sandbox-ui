## Overview

`KV` renders a two-column label/value grid, ideal for sandbox detail panels, resource metadata, and configuration summaries. Individual items can be made copyable — clicking the copy button writes the value to the clipboard and shows transient feedback.

## Accessibility

- Copy buttons use `aria-label="Copy value"` and include an `aria-live="polite"` region that announces "Copied" / "Failed" after the clipboard write.
- The grid layout uses CSS (`display: contents` on item wrappers) — the DOM order matches the visual order for screen readers.
