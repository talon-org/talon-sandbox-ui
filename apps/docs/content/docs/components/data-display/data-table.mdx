## Overview

`DataTable` wraps TanStack Table v8 with Talon's visual system. It supports two modes:

- **`client`** (default) — TanStack Table owns sorting, filtering, and pagination state internally. Pass `columns`, `data`, and feature flags.
- **`server`** — caller owns all state via `serverState`. `DataTable` renders controls only; no internal state mutations.

Use client mode for in-memory datasets (≤ 10k rows). Use server mode when data is fetched from an API with server-side sort/filter/page.

### Feature matrix

| Feature | client | server |
|---------|--------|--------|
| Column sort | `sorting` prop | via `serverState.sorting` |
| Global filter input | `filtering` prop | via `serverState.globalFilter` |
| Pagination | `pagination` prop | via `serverState.page` / `pageSize` |
| Row selection | `rowSelection` prop | `rowSelection` prop |
| Column visibility | `columnVisibility` prop (default on) | same |
| Row virtualization | Auto when > 500 rows | — |

## Usage

```tsx
import { DataTable } from '@talon-sandbox/react';
import type { ColumnDef } from '@talon-sandbox/react';

type Sandbox = { id: string; name: string; status: string; region: string };

const columns: ColumnDef<Sandbox>[] = [
  { accessorKey: 'id', header: 'ID' },
  { accessorKey: 'name', header: 'Name' },
  { accessorKey: 'status', header: 'Status' },
  { accessorKey: 'region', header: 'Region' },
];

// Client mode
<DataTable
  columns={columns}
  data={sandboxes}
  sorting
  filtering
  pagination={{ pageSize: 25, pageSizeOptions: [10, 25, 50] }}
/>

// Server mode
<DataTable
  columns={columns}
  data={page}
  mode="server"
  serverState={{
    total: 1200,
    page,
    pageSize,
    onPageChange: setPage,
    onPageSizeChange: setPageSize,
    sorting: sortState,
    onSortingChange: setSortState,
    globalFilter: query,
    onGlobalFilterChange: setQuery,
  }}
/>
```

## Keyboard behavior

| Key | Effect |
|-----|--------|
| `Tab` | Move focus through interactive cells and controls |
| `Enter` / `Space` on header | Toggle sort direction |
| `Space` on checkbox cell | Toggle row selection |
| Arrow keys in filter input | Standard text navigation |

## Accessibility

- The `<table>` element uses semantic HTML — `<thead>`, `<tbody>`, `<th scope="col">`.
- Sortable column headers have `aria-sort="ascending"` / `"descending"` / `"none"`.
- The global filter input has a visible label or `aria-label="Filter"`.
- Row checkboxes have `aria-label="Select row"` and the header checkbox has `aria-label="Select all"`.
- Empty state uses `role="status"` so screen readers announce it on data changes.

## Performance

- Row virtualization activates automatically when `data.length > 500` (renders only visible rows). Override with `virtualization={false}` or `virtualization={{ estimateSize: 48 }}` to set row height estimate.
- Pass a stable `columns` reference (module-level constant or `useMemo`) — column redefinitions on every render trigger full table rebuilds.
- For large server datasets, combine `mode="server"` with debounced `onGlobalFilterChange` to avoid per-keystroke API calls.
