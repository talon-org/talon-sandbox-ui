## Overview

`SandboxStateBar` renders a segmented bar + legend showing how many sandboxes are in each lifecycle state. Each segment's width is proportional to its count relative to the total.

Use it on dashboard and monitoring pages where operators need an at-a-glance distribution across states.

## Live demo

<Preview minHeight={120}>
  <SandboxStateBar
    counts={{
      running: 42,
      idle: 15,
      provisioning: 3,
      'pulling-image': 2,
      failed: 1,
      stopped: 0,
    }}
  />
</Preview>

## Sparse counts

Only states with a non-zero count render a segment. States with count `0` appear in the legend with muted styling.

<Preview minHeight={120}>
  <SandboxStateBar
    counts={{ running: 10, failed: 2 }}
  />
</Preview>

## Accessibility

- The segmented track has `role="img"` with `aria-label="Sandbox state distribution"`.
- Each segment has a `title` tooltip with the full label and count (e.g. "Running: 42").
- Legend color swatches use `aria-hidden="true"` — the text label and count convey the full meaning.
