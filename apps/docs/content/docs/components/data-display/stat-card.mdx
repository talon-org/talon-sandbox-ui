## Overview

`StatCard` displays a single numeric metric with a label, value, optional unit, optional delta, and optional icon. `StatCardGrid` arranges multiple cards in a 2–4 column responsive grid.

## Accessibility

- `delta` is read by screen readers via `aria-label` that prepends "上升" (up) or "下降" (down) when `deltaKind` is `up`/`down`.
- `StatCard` uses a `<div>` and does not have inherent interactive role — do not put clickable actions inside the value area.
