## Overview

`FilterBar` renders a row of filter pills grouped by category, with optional counts per item and a search input on the right. It is the primary filtering control for list and table pages in the Talon console.

## Accessibility

- Each filter pill is a `<button>` with `aria-pressed` reflecting whether it is the active filter.
- Group labels are rendered as plain text separators — they do not have a heading role; the visual grouping is presentational.
- The search input accepts all standard `<input>` keyboard behavior.
