## Overview

`PageHeader` provides the standard title block at the top of list and detail pages. It renders a semantic heading (`h1` by default), with optional eyebrow label, count badge appended to the title, description line, and an end-aligned actions slot.

## Nested heading level

When `PageHeader` is used inside a card or section (not the page root), pass `headingLevel={2}` or `headingLevel={3}` to maintain correct document outline.

<Preview minHeight={80}>
  <PageHeader
    title="Section title"
    headingLevel={2}
    noBorder
  />
</Preview>

## Accessibility

- `title` renders as an `<h1>` by default — use only once per page. Use `headingLevel` for nested headers.
- `num` (count badge) is appended inline inside the heading — it is read as part of the heading text by screen readers.
- `actions` slot content should have their own accessible names (e.g., `<Button>New sandbox</Button>`).
