## Overview

`LoginLayout` provides the standard two-column layout for authentication pages: a full-height decorative `left` panel (brand, illustration, or copy) and a centered form panel on the `right`.

## Accessibility

- The layout renders two sibling `<div>` elements — no implied roles.
- The form inside `children` should use `<form>` with a submit handler, `<label>` elements associated with each input, and a submit `<Button type="submit">`.
- The `left` decorative panel should not contain content critical to completing the login flow — it should be meaningful only as brand reinforcement.
