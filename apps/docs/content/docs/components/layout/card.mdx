## Overview

`Card` is the standard surface container in Talon — a bordered, rounded box with optional title header and footer slots. `Panel` is a direct alias exported from the same module; use either name, they are identical.

### When to use

- Grouping related content on dashboard and detail pages.
- Wrapping a form section that needs visual separation.
- Displaying metrics, resource panels, or any content that needs a distinct surface.

## Accessibility

- `Card` renders a `<div>` — it has no inherent role.
- If the card represents a distinct content region, wrap it in a `<section>` or add `role="region"` with an `aria-label`.
- The `title` prop renders as a `<div>` — it is visual only. Add a heading element inside `children` if the card title needs to appear in the document outline.
