## Overview

`MemberRow` renders a standardized row for team member lists. It shows an avatar (initials or a custom image), email, optional role badge, optional joined date, and an end-aligned actions slot.

## Accessibility

- The avatar element has `aria-hidden="true"` — the email address serves as the primary identifier for screen readers.
- `role` and `joinedAt` are supplementary text; ensure `actions` buttons have their own visible labels or `aria-label` values that include context (e.g., "Remove alice@example.com").
