## Overview

`TweaksPanel` is the design-token control surface that ships with every `<Preview>` island on this documentation site. It exposes five axes:

| Axis | Values |
|------|--------|
| **Theme** | ink, onyx, pewter, iron, phosphor, indigo, violet, sky, teal |
| **Mode** | dark, light |
| **Density** | compact, standard, relaxed |
| **Font** | Geist, IBM Plex Mono, JetBrains Mono, System |
| **Language** | EN, 中文 |

Changing any control calls `onSet(key, value)` — the parent is responsible for applying the value to the appropriate `data-*` attribute on the containing element and persisting it.

### Integration in Preview

The `Preview` component on this docs site manages all five axes in local state and persists them to `localStorage` under keys `tln:v2:theme`, `tln:v2:mode`, `tln:v2:density`, `tln:v2:font`, `tln:v2:lang`. `TweaksPanel` is pinned to the top-right corner of each preview and starts collapsed (`defaultOpen={false}`).

### Using TweaksPanel in your own app

`TweaksPanel` is a **fully controlled** component — it does not manage state or write `data-*` attributes itself. Wire it up like this:

```tsx
import { useState } from 'react';
import { TweaksPanel } from '@talon-sandbox/react';

function App() {
  const [theme, setTheme] = useState('ink');
  const [mode, setMode] = useState<'dark' | 'light'>('dark');
  const [density, setDensity] = useState<'compact' | 'standard' | 'relaxed'>('standard');
  const [font, setFont] = useState<'geist' | 'plex' | 'jetbrains' | 'system'>('geist');
  const [lang, setLang] = useState<'en' | 'zh'>('en');

  const handleSet = (key: string, value: string) => {
    // 1. Update state
    if (key === 'theme') setTheme(value);
    if (key === 'mode') setMode(value as 'dark' | 'light');
    // ... etc.

    // 2. Apply to root
    document.documentElement.setAttribute(`data-${key}`, value);

    // 3. Persist
    localStorage.setItem(`tln:v2:${key}`, value);
  };

  return (
    <div data-theme={theme} data-mode={mode} data-density={density} data-font={font} data-lang={lang}>
      <TweaksPanel
        theme={theme} mode={mode} density={density} font={font} lang={lang}
        onSet={handleSet}
        defaultOpen={false}
      />
      {/* app content */}
    </div>
  );
}
```

## Accessibility

- The panel toggle button uses `aria-expanded` reflecting open/closed state.
- Theme swatch buttons use `aria-pressed` and `aria-label={themeName}` so screen readers announce which theme is active.
- All `Segmented` controls inside the panel carry their own `role="group"` and `aria-pressed` semantics — see the [Segmented](/docs/components/forms/segmented) documentation.
