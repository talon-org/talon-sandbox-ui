## Overview

`Select` wraps the native `<select>` element. It keeps native mobile UX (keyboard, scroll, iOS picker) while applying Talon's sizing tokens and custom arrow. Use it for short, static option lists where searchability is not needed.

### When to use vs Combobox vs MultiSelect

| | Select | Combobox | MultiSelect |
|--|--------|---------|------------|
| **Options count** | ≤15 | Any (searchable) | ≤30 |
| **Multi-select** | No | No | Yes |
| **Searchable** | No | Yes | Partial |
| **Native mobile UX** | Yes | No | No |

## Keyboard behavior

Inherits native `<select>` keyboard behavior: `Space` opens, `Arrow Up/Down` navigates, `Enter` confirms, `Escape` cancels.

## Accessibility

- Always associate with a label via `<label htmlFor>` or wrap in `FormField`.
- `invalid` sets `aria-invalid="true"` on the select element.
