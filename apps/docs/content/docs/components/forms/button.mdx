## Overview

`Button` is the primary interactive control. Every user-initiated action in the console flows through a Button. It intentionally does **not** emit any Tailwind classes — all styling lives in `@talon-sandbox/react/styles` via `tln-btn*` CSS classes.

### When to use

- `variant="primary"` — the single most important action on a screen (create, submit, confirm). **Limit one primary button per view.**
- `variant="default"` — secondary actions that are important but not the primary CTA.
- `variant="ghost"` — low-emphasis actions: cancel, dismiss, navigate back, toolbar controls.
- `variant="danger"` — irreversible destructive actions (delete, revoke). Always pair with a confirmation dialog.
- `iconOnly` — toolbar actions where space is constrained. Always supply `aria-label`.

### When NOT to use

- Navigation that changes the URL — use `<a>` with appropriate styling instead.
- Multiple `primary` buttons on the same screen.
- `danger` for soft/reversible actions.

The `loading` prop renders a spinner, disables the button, and sets `aria-busy="true"`.

## Keyboard behavior

| Key | Effect |
|-----|--------|
| `Space` / `Enter` | Activates the button |
| `Tab` | Moves focus forward |
| `Shift+Tab` | Moves focus backward |

## Accessibility

- Always supply visible text content or `aria-label` for icon-only buttons.
- `loading` buttons automatically set `aria-busy="true"` and the HTML `disabled` attribute.
- `type="button"` is set by default — use `type="submit"` explicitly inside forms.
- Rendered as a native `<button>` — no ARIA role override needed.

## Recipes

### Confirmation flow (Button → Dialog → Toast)

```tsx
import { useState } from 'react';
import { Button, Dialog, toast, ToastViewport } from '@talon-sandbox/react';

function DeleteSandbox({ id }: { id: string }) {
  const [open, setOpen] = useState(false);
  const [loading, setLoading] = useState(false);

  async function handleDelete() {
    setLoading(true);
    try {
      await api.deleteSandbox(id);
      toast.success('Sandbox deleted');
      setOpen(false);
    } catch {
      toast.error('Failed to delete sandbox');
    } finally {
      setLoading(false);
    }
  }

  return (
    <>
      <ToastViewport />
      <Button variant="danger" onClick={() => setOpen(true)}>Delete</Button>
      <Dialog
        open={open}
        onClose={() => setOpen(false)}
        title="Delete sandbox?"
        footer={
          <div style={{ display: 'flex', gap: 8, justifyContent: 'flex-end' }}>
            <Button variant="ghost" onClick={() => setOpen(false)}>Cancel</Button>
            <Button variant="danger" loading={loading} onClick={handleDelete}>Delete</Button>
          </div>
        }
      >
        <p>This will permanently destroy <strong>{id}</strong>. This cannot be undone.</p>
      </Dialog>
    </>
  );
}
```
