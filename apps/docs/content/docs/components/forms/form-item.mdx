## Overview

`FormItem` connects a TanStack Form `AnyFieldApi` to `FormField`, automatically surfacing the first validation error from `field.state.meta.errors` and hiding it until the field has been touched. It uses the render-prop pattern — children is a function that receives the `field` and returns the input JSX.

### When to use vs FormField

| | FormItem | FormField |
|--|----------|-----------|
| **Form library** | TanStack Form v1 | Any / none |
| **Error wiring** | Automatic from `field.state` | Manual via `error` prop |
| **Label/hint** | Same API | Same API |

## Usage

```tsx
import { useForm } from '@tanstack/react-form';
import { FormItem, Input, Button } from '@talon-sandbox/react';

function CreateSandboxForm() {
  const form = useForm({
    defaultValues: { name: '' },
    onSubmit: ({ value }) => api.createSandbox(value),
  });

  return (
    <form onSubmit={(e) => { e.preventDefault(); form.handleSubmit(); }}>
      <form.Field
        name="name"
        validators={{ onChange: ({ value }) => !value ? 'Required' : undefined }}
      >
        {(field) => (
          <FormItem field={field} label="Sandbox name" required>
            {(f) => (
              <Input
                value={f.state.value}
                onChange={(e) => f.handleChange(e.target.value)}
                onBlur={f.handleBlur}
              />
            )}
          </FormItem>
        )}
      </form.Field>
      <Button type="submit">Create</Button>
    </form>
  );
}
```

## Props

`FormItem` accepts `field: AnyFieldApi` plus the same `label`, `hint`, `required`, and `className` props as `FormField`. There is no separate `.types.ts` — see the types below:

| Prop | Type | Description |
|------|------|-------------|
| `field` | `AnyFieldApi` | TanStack Form field API instance (from `form.Field` render prop) |
| `label` | `ReactNode` | Optional label |
| `hint` | `ReactNode` | Optional hint shown below the control |
| `required` | `boolean` | Adds required marker to label |
| `children` | `(field: AnyFieldApi) => ReactNode` | Render prop — receives the same `field` for wiring value/onChange/onBlur |

## Accessibility

- Delegates to `FormField` internally — all the same accessible ID injection and `aria-invalid` wiring applies.
- Errors from `field.state.meta.errors` are only shown after `field.state.meta.isTouched` is true, preventing flash-of-error on initial render.
