## Overview

`Textarea` wraps the native `<textarea>` with Talon's token styling. Use it for multi-line free text: notes, descriptions, startup scripts, configuration snippets.

### When to use vs Input

- Use `Textarea` when the expected content is more than one line.
- Use `Input` for single-line values.
- Use `CodeBlock` for read-only code display — don't put code into a Textarea.
