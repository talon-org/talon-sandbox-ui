## Overview

`Input` wraps the native `<input>` element with design-system sizing tokens, an invalid state, monospace mode, and prefix/suffix adornment slots. Use it everywhere you'd use a bare `<input>` — it guarantees consistent height, font, and border styling across all Talon surfaces.

### When to use

- Single-line free text: names, IDs, URLs, search queries, API tokens.
- With `prefix`/`suffix` for icon buttons, clear buttons, or unit labels.
- For multi-line content use `Textarea`. For numeric values use `NumberInput`.

### Gotcha: `className` placement

`className` applies to the **outermost element**: the `<input>` when no adornments are present, or the `.tln-input-wrap` div when adornments are present. This means width/margin on `className` works correctly in both cases. The inner `<input>` does **not** receive `className` when wrapped.

## Keyboard behavior

Inherits native `<input>` keyboard behavior. No custom keyboard handling.

## Accessibility

- Always associate with a label via `<label htmlFor>` — use `FormField` for the label+input pattern.
- `invalid` sets `aria-invalid="true"` on the underlying input element.
- Prefix/suffix adornments are in non-interactive `<span>` wrappers — ensure any interactive elements inside have their own accessible names.
