## Overview

`Checkbox` renders an accessible `<input type="checkbox">` with Talon styling. It supports three states: unchecked, checked, and indeterminate. The indeterminate state is typically used in "select all" table headers where a subset of rows is selected.

### Checkbox vs Switch

| | Checkbox | Switch |
|--|----------|--------|
| **Effect timing** | Deferred — collected at form submit | Immediate — applies on change |
| **Best for** | Multi-select, form options | Feature flags, live settings |
| **Semantic** | `<input type="checkbox">` | `role="switch"` |

## Usage

```tsx
import { Checkbox } from '@talon-sandbox/react';

// Controlled
<Checkbox checked={agreed} onChange={setAgreed}>
  Accept terms of service
</Checkbox>

// Indeterminate select-all
<Checkbox
  checked={allSelected}
  indeterminate={someSelected && !allSelected}
  onChange={toggleAll}
>
  Select all
</Checkbox>
```

## Keyboard behavior

| Key | Effect |
|-----|--------|
| `Space` | Toggle checked state |
| `Tab` / `Shift+Tab` | Move focus |

## Accessibility

- Uses a native `<input type="checkbox">` for full browser and AT support.
- `indeterminate` is set via the DOM property (not an HTML attribute) — screen readers announce "mixed" state.
- When rendered inside `FormField`, automatically receives `id` from context and `aria-invalid` when an error is present.
- `disabled` renders `aria-disabled` and prevents interaction.
