## Overview

`Combobox` renders a text input that filters a dropdown of options as the user types. The built-in filter does a case-insensitive substring match against `option.label`. For async or server-side filtering, set `filterExternal` and wire `onQueryChange` to your fetch/debounce logic.

### When to use vs Select vs MultiSelect

| | Combobox | Select | MultiSelect |
|--|----------|--------|-------------|
| **Searchable** | Yes | No | No |
| **Multiple values** | No | No | Yes |
| **Async options** | Yes (`filterExternal`) | No | No |
| **Best for** | Image pickers, user search | Short static lists | Region/tag pickers |

## External filter

Use `filterExternal` when options are fetched from a server. The built-in filter is disabled; pass a filtered `options` array and update it via `onQueryChange`.

## Usage

```tsx
import { Combobox } from '@talon-sandbox/react';

const IMAGES = [
  { value: 'ubuntu-22.04', label: 'ubuntu:22.04' },
  { value: 'debian-12', label: 'debian:12' },
];

// Built-in filter
<Combobox
  options={IMAGES}
  value={image}
  onChange={setImage}
  placeholder="Search images…"
/>

// External / async filter
<Combobox
  options={filteredOptions}
  value={image}
  onChange={setImage}
  filterExternal
  onQueryChange={(q) => debouncedFetch(q)}
  loading={isLoading}
  emptyLabel="No matching images"
/>
```

## Keyboard behavior

| Key | Effect |
|-----|--------|
| `ArrowDown` | Open dropdown / move focus to next option |
| `ArrowUp` | Move focus to previous option |
| `Enter` | Select focused option |
| `Escape` | Close dropdown, restore previous value |
| `Tab` | Close dropdown and move focus out |

## Accessibility

- Input has `role="combobox"` with `aria-expanded`, `aria-autocomplete="list"`, and `aria-haspopup="listbox"`.
- Each option has `role="option"` with `aria-selected`.
- `aria-activedescendant` tracks the currently highlighted option.
- The loading indicator is `aria-hidden`; an `aria-live="polite"` region announces option-count changes for screen reader users.
- Disabled options have `aria-disabled="true"` and are skipped during keyboard navigation.
