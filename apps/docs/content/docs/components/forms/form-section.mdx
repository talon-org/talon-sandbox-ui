## Overview

`FormSection` groups related form fields under a titled block with an optional icon and hint. `FormGrid` lays out fields in a responsive 1- or 2-column grid inside a section.

Use them together to create structured, scannable settings forms — the section provides the heading hierarchy and the grid handles the column rhythm.

### When to use

- Settings pages with multiple logical groups (General, Security, Notifications…).
- Any form with 4+ fields where visual grouping helps users orient themselves.
- Prefer `FormSection` + `FormGrid` + `FormField` as the standard Talon form assembly. Flat field lists without a section wrapper are acceptable only for compact 1–3 field forms.

## Accessibility

- `FormSection` renders a `<div>` — use `FormField` inside to associate labels with inputs via `htmlFor`.
- The title text provides visual grouping; add a wrapping `<fieldset>` + `<legend>` when the group needs semantic meaning for screen readers (e.g., a radio group).
