## Overview

`Segmented` renders a compact pill group where exactly one option is active at a time. It is the right choice when switching between 2–5 views, modes, or settings where all options are visible simultaneously.

### When to use vs Tabs vs RadioGroup

| | Segmented | Tabs | RadioGroup |
|--|-----------|------|-----------|
| **Content behind control** | No (state only) | Yes (panel swap) | No (form value) |
| **Option count** | 2–5 | 3–8 | Any |
| **Visual weight** | Compact | Standard | Form-weight |
| **Example** | Dark/Light toggle, density picker | Overview / Logs / Settings | Policy type selection |

## Keyboard behavior

| Key | Effect |
|-----|--------|
| `ArrowRight` | Select next option |
| `ArrowLeft` | Select previous option |
| `Home` | Select first option |
| `End` | Select last option |

## Accessibility

- Container has `role="group"`.
- Each button has `aria-pressed` reflecting selection state.
- Disabled options have `aria-disabled="true"`.
