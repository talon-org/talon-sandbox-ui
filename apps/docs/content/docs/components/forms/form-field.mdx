## Overview

`FormField` wraps any form control with a label, optional hint, and optional validation error. It generates a stable `id` via `useId()` and injects it into context so that child controls can read it without prop-drilling.

Controls built on `FormField` context — `Input`, `Select`, `Textarea`, `NumberInput`, `Checkbox` — automatically receive the generated `id` and `aria-invalid` when wrapped.

### When to use

Use `FormField` any time a form control needs:
- A visible label connected via `htmlFor`/`id`
- A hint line below the control
- Inline validation error display

For TanStack Form integration, use [`FormItem`](/docs/components/forms/form-item) instead.

## Usage

```tsx
import { FormField, Input } from '@talon-sandbox/react';

<FormField
  label="Sandbox name"
  hint="Used as the container hostname."
  error={nameError}
  required
>
  <Input value={name} onChange={(e) => setName(e.target.value)} />
</FormField>
```

## Accessibility

- `FormField` renders a `<label>` whose `htmlFor` matches the child control's `id` — either from the `htmlFor` prop or auto-generated via `useId()`.
- When `error` is set, child controls that consume `FormFieldContext` automatically receive `aria-invalid="true"` and `aria-describedby` pointing to the error message.
- The required marker (`*`) is `aria-hidden`; `required` on the underlying `<input>` conveys required status to assistive technology.
