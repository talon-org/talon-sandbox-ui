## Overview

`RadioGroup` renders a set of mutually exclusive options. It comes in two visual variants:

- **default** — compact radio pills, suitable for 2–6 options in forms
- **card** — bordered selectable cards, suitable for top-level plan/tier selection

Use `Radio` directly only when composing a custom layout. For standard use, `RadioGroup` with an `options` array is preferred.

### When to use vs Segmented vs Select

| | RadioGroup | Segmented | Select |
|--|------------|-----------|--------|
| **Options visible** | Always | Always | Hidden (dropdown) |
| **Option count** | 2–6 | 2–5 | Any |
| **Best for** | Settings, forms | Mode toggles | Long option lists |

## Keyboard behavior

| Key | Effect |
|-----|--------|
| `ArrowDown` / `ArrowRight` | Select next option |
| `ArrowUp` / `ArrowLeft` | Select previous option |
| `Tab` | Move focus out of group |

## Accessibility

- Container uses `role="radiogroup"`.
- Each radio uses `role="radio"` with `aria-checked`.
- Arrow keys cycle selection within the group; `Tab` moves focus out.
- `disabled` on the group or individual options sets `aria-disabled="true"`.
