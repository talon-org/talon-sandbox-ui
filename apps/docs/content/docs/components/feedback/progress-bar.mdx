## Overview

`ProgressBar` renders a horizontal progress fill. Use the determinate mode when you know the percentage complete; use `indeterminate` for operations where progress is unknown (image pull, connection wait).

## Accessibility

- Uses `role="progressbar"` with `aria-valuenow`, `aria-valuemin`, and `aria-valuemax`.
- Indeterminate mode omits `aria-valuenow` per ARIA spec (value is not currently known).
- Provide an `aria-label` or `aria-labelledby` when the progress bar is standalone and the surrounding text does not describe it — e.g. `<ProgressBar indeterminate aria-label="Loading sandboxes" />`.
