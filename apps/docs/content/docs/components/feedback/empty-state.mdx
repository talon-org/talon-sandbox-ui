## Overview

`EmptyState` provides a centered visual placeholder when a list, table, or panel has no data to show. It accepts an optional icon, eyebrow label, title, description, and an action slot for a primary CTA.

### When to use

- Empty list pages ("No sandboxes yet").
- Zero-results search feedback.
- First-run onboarding prompts ("Create your first sandbox").
- Error states where recovery requires an action.

## Accessibility

- `EmptyState` renders a plain `<div>` — it is not interactive by itself.
- The `action` slot should contain a focusable element (e.g., `Button`) with an appropriate label.
- `title` renders as text — do not rely solely on the icon to communicate the state.
