## Overview

The toast system has two parts:

- **`toast`** — a singleton imperative API that fires notifications from anywhere in your app, no context provider required.
- **`ToastViewport`** — the rendered stack mounted once at the root of your app. It subscribes to the singleton and renders the live list into a portal.

### When to use

Use toasts for **transient, non-blocking feedback** about actions that just completed:
- "Sandbox created" (success)
- "Failed to restart sandbox" (error)
- "Token copied to clipboard" (default)

Do not use toasts for:
- Errors that require user action — use a Dialog or inline validation.
- Persistent status — use `StatusBadge` or `SandboxStateBar`.

## Setup

Mount `ToastViewport` once at the top of your app — typically in `App.tsx` or a layout component:

```tsx
import { ToastViewport } from '@talon-sandbox/react';

export function App() {
  return (
    <>
      <ToastViewport />
      {/* your routes / layout */}
    </>
  );
}
```

## Usage

```tsx
import { toast } from '@talon-sandbox/react';

// Default
toast('Copied to clipboard');

// Variants
toast.success('Sandbox created');
toast.error('Failed to start sandbox');
toast.info('Deployment queued');
toast.warn('CPU quota at 90%');

// Dismiss
const id = toast('Long-running operation…');
toast.dismiss(id);

// Dismiss all
toast.dismiss();
```

## Behavior

- Toasts auto-dismiss after 3.5 seconds.
- Hovering a toast pauses the auto-dismiss timer; moving the mouse away resumes it.
- The dismiss button removes the toast immediately.
- New toasts stack above existing ones.

## toast API

| Method | Description |
|--------|-------------|
| `toast(message)` | Show a default toast |
| `toast.success(message)` | Success variant |
| `toast.error(message)` | Error variant |
| `toast.info(message)` | Info variant |
| `toast.warn(message)` | Warning variant |
| `toast.dismiss(id?)` | Dismiss by id; omit id to dismiss all |

## Accessibility

- `ToastViewport` container uses `role="region"` with `aria-live="polite"` and `aria-label="Notifications"` — new toasts are announced by screen readers.
- Each toast uses `role="status"`.
- The dismiss button has `aria-label="Dismiss notification"`.
