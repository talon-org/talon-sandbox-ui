# Colour Tokens

All colour values live in `packages/tokens/src/tokens.css` and are generated by an OKLCh algorithm — hue fixed, lightness and chroma derived perceptually.

---

## Surfaces

Background levels. Use at most 3 levels in a single view.

| Token | Ink dark | Ink light | Usage |
|---|---|---|---|
| `--bg-0` | `#000000` | `#f1f2f5` | True black — page edge / terminal background |
| `--bg-1` | `#08090b` | `#fdfdff` | Main background, most page bodies |
| `--bg-2` | `#151618` | `#f4f5f9` | Cards, tables, panels |
| `--bg-3` | `#232426` | `#eaebef` | Drawers, dialogs, popovers |
| `--bg-4` | `#343538` | `#dddee1` | Tooltips, dropdown item hover |
| `--bg-input` | `#08090b` | `#fdfdff` | Form field background |
| `--bg-hover` | `rgba(255,255,255,0.04)` | `rgba(15,20,35,0.035)` | Row hover micro-feedback |
| `--bg-active` | `rgba(255,255,255,0.07)` | `rgba(15,20,35,0.065)` | Active / pressed state |

**Rule**: at most 3 bg levels per view. `--bg-0` appears only under floating layers or as a terminal true-black.

## Lines

Alpha-based dividers. Theme-neutral — unaffected by `data-theme`, only by `data-mode`.

| Token | Dark value | Light value | Usage |
|---|---|---|---|
| `--line-soft` | `rgba(255,255,255,0.07)` | `rgba(15,20,35,0.05)` | Internal dividers (between table rows) |
| `--line` | `rgba(255,255,255,0.14)` | `rgba(15,20,35,0.09)` | Default border (cards, buttons, inputs) |
| `--line-strong` | `rgba(255,255,255,0.22)` | `rgba(15,20,35,0.16)` | Hover / focus emphasis |
| `--line-emphasis` | `rgba(255,255,255,0.32)` | `rgba(15,20,35,0.26)` | Active / selected |

**Rule**: 80% of dividers use `--line-soft` / `--line`. Separate with contrast and whitespace; avoid thick frames.

## Accent

Component code always references `--acc` / `--acc-*`, never specific hue values. Switching themes replaces the whole group automatically.

Values below use the default Ink theme as example:

| Token | Ink dark | Usage |
|---|---|---|
| `--acc` | `#3e50d3` | Primary action, selected state, focus ring |
| `--acc-1` | `#0b1023` | Darkest chip background |
| `--acc-2` | `#0f163b` | Second-darkest / `--acc-soft` |
| `--acc-3` | `#17205e` | Darker border background |
| `--acc-4` | `#273493` | High-contrast border / `--acc-line` |
| `--acc-5` | `#3e50d3` | Solid primary (= `--acc`) |
| `--acc-6` | `#303cbe` | Hover |
| `--acc-7` | `#95acff` | Text on accent / `--acc-strong` |
| `--acc-fg` | `#ebecf0` | Foreground text on accent-filled background |
| `--acc-soft` | `#0f163b` | Chip / selected row fill |
| `--acc-line` | `#273493` | Accent border |

**Rule**: accent appears at most 5 times per view. Treat it as a scarce resource.

## Status (semantically fixed)

Status colours adapt between dark and light mode. They do not change with `data-theme` — except in themes where a clash would occur (auto-resolved).

Each status provides a full system: `--<name>-1..7` + `--<name>` + `--<name>-fg` + `--<name>-soft` + `--<name>-line` + `--<name>-strong` + `--<name>-dim`.

| Token | Dark solid | Semantic | Clash exception |
|---|---|---|---|
| `--ok` | `#399e43` | Running / healthy / check passed | phosphor/teal themes auto-replace |
| `--warn` | `#d38f01` | Quota approaching / warning / pending | — |
| `--err` | `#c34f51` | Failed / error / over quota | iron theme auto-replaces |
| `--info` | `#019ec7` | Streaming / new event | — |
| `--magenta` | `#ad70d7` | Credentials / encrypted / admin | — |
| `--teal` | `#01b8a1` | Port / network / tunnel | — |

Common alias patterns:

```css
/* Status chip */
background: var(--ok-soft);
color: var(--ok-strong);
border: 1px solid var(--ok-line);

/* Solid status badge */
background: var(--ok);
color: var(--ok-fg);
```

**Rule**: status colours are for status only, not brand decoration. Error colour is always red-family — do not redefine it.

## Focus indicators

| Token | Dark | Light |
|---|---|---|
| `--border-focus` | `#3a4cad` | `#2b2ec2` |
| `--shadow-focus` | `0 0 0 3px rgba(62,80,211,0.3)` | `0 0 0 3px rgba(43,46,194,0.18)` |
| `--shadow-focus-err` | `0 0 0 3px rgba(195,79,81,0.3)` | `0 0 0 3px rgba(167,0,35,0.18)` |

Focus ring colour tracks `data-theme` — each theme injects its own `--shadow-focus`.
