# TweaksPanel

Floating control panel for live theme, mode, density, font, and language switching. Used in this docs site itself (top-right corner) and in the Talon Sandbox Playground.

## When to use

- Developer-facing settings panel in a dev/playground context.
- Anywhere you want to expose `data-theme` / `data-mode` / `data-density` switching to end users.

## When NOT to use

- Production app settings UI — TweaksPanel is developer-ergonomic, not designed for end-user settings pages. For production settings, build a proper settings form with `Switch`, `Select`, and `RadioGroup`.

## State ownership

TweaksPanel is **fully controlled** — it does not own state. You hold theme/mode/density/font/lang in your state and apply them to `document.documentElement.dataset` or a wrapping element's `data-*` attributes. The `onSet` callback gives you the key and new value.

```tsx
const [theme, setTheme] = useState<TweaksTheme>('ink');
const [mode, setMode] = useState<TweaksMode>('dark');

<TweaksPanel
  theme={theme} mode={mode} density="standard" font="geist" lang="en"
  onSet={(key, value) => {
    document.documentElement.dataset[key] = value;
    if (key === 'theme') setTheme(value as TweaksTheme);
    if (key === 'mode')  setMode(value as TweaksMode);
  }}
/>
```

## THEME_SWATCHES

The exported `THEME_SWATCHES` constant contains all 9 themes with their accent color for swatch rendering:

```ts
THEME_SWATCHES = [
  { id: 'ink',      label: 'Ink',      bg: '#7d97ff' },
  { id: 'onyx',     label: 'Onyx',     bg: '#e6cf4a' },
  // ...9 total
]
```

## Examples

### Default (open)

export const DefaultOpen = () => {
  const [theme, setTheme]     = useState('ink');
  const [mode, setMode]       = useState('dark');
  const [density, setDensity] = useState('standard');
  const [font, setFont]       = useState('geist');
  const [lang, setLang]       = useState('en');

  return (
    <div style={{ padding: 16, position: 'relative', minHeight: 300 }}>
      <p style={{ color: 'var(--fg-3)', fontSize: 12, marginTop: 0 }}>
        Current: theme={theme} mode={mode} density={density} font={font} lang={lang}
      </p>
      <TweaksPanel
        theme={theme as any}
        mode={mode as any}
        density={density as any}
        font={font as any}
        lang={lang as any}
        defaultOpen={true}
        onSet={(key, value) => {
          if (key === 'theme')   setTheme(value);
          if (key === 'mode')    setMode(value);
          if (key === 'density') setDensity(value);
          if (key === 'font')    setFont(value);
          if (key === 'lang')    setLang(value);
        }}
      />
    </div>
  );
};

## Accessibility checklist

- The toggle button has `aria-expanded` reflecting the open state.
- Theme swatches have `aria-pressed` (active theme) and `aria-label` (theme name) and `title` (tooltip).
- Mode/density/font/lang controls use `Segmented` which has full keyboard and ARIA support.
