# RecordingPlayer

Full-featured terminal recording playback component. Renders a scrolling terminal output area with a scrubber, play/pause, speed control, and optional step sidebar.

## Controlled interface

RecordingPlayer is **fully controlled** — the parent holds `currentTime` and `isPlaying` in state and wires them back as props. The component drives its own `requestAnimationFrame` loop when `isPlaying` is true, calling `onSeek` each frame and `onTogglePlay` when playback reaches `recording.duration`.

This design lets you:
- Sync multiple players to the same time
- Persist playback position to localStorage
- Override playback from outside (e.g. clicking a step in a list)

## Architecture: binary search frame visibility

`binarySearch(frames, currentTime)` is exported for external use. It returns the count of frames with `time <= currentTime` in O(log n) — safe for 10k+ frame recordings. The component uses this internally to compute visible frames.

## Examples

### Minimal playback

export const MinimalPlayback = () => {
  const [t, setT] = useState(0);
  const [playing, setPlaying] = useState(false);
  const [speed, setSpeed] = useState(1);

  const recording = { id: 'rec-001', name: 'hello-world run', duration: 12 };
  const frames = [
    { time: 0.5,  text: '$ npm install', kind: 'cmd' as const },
    { time: 1.0,  text: 'added 312 packages', kind: 'out' as const },
    { time: 2.5,  text: '$ node index.js', kind: 'cmd' as const },
    { time: 3.0,  text: 'Server listening on :3000', kind: 'ok' as const },
    { time: 5.0,  text: 'GET / 200 12ms', kind: 'out' as const },
    { time: 7.0,  text: 'GET /api/health 200 3ms', kind: 'out' as const },
    { time: 9.0,  text: 'Server shutting down…', kind: 'out' as const },
    { time: 10.5, text: 'Process exited with code 0', kind: 'ok' as const },
  ];

  return (
    <div style={{ padding: 16 }}>
      <RecordingPlayer
        recording={recording}
        frames={frames}
        currentTime={t}
        onSeek={setT}
        isPlaying={playing}
        onTogglePlay={() => setPlaying(p => !p)}
        speed={speed}
        onSpeedChange={setSpeed}
        onBack={() => alert('back')}
      />
    </div>
  );
};

## Accessibility checklist

- The scrubber `<input type="range">` has `aria-label="Seek"`.
- Play/pause button has `aria-label={isPlaying ? 'Pause' : 'Play'}`.
- Speed options have `aria-pressed` to indicate the active speed.
- Step items are `role="button"` with `tabIndex={0}` and keyboard support (`Enter`/`Space`).
