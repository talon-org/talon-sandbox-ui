# CmdKOverlay

Command palette overlay with fuzzy search, keyboard navigation, and grouped items. Renders into a portal at `document.body`.

## When to use

- Global "⌘K / Ctrl+K" shortcut for power-user access to all actions.
- Context-specific action palettes (e.g. "actions for this sandbox").
- Any scenario where a searchable list of commands improves discoverability.

## When NOT to use

- Lists that aren't actions — use `Select` or `Combobox` for value selection.
- Navigation-only patterns — a sidebar with links is clearer.

## Anatomy

```
[backdrop — click to close]
  role="dialog" aria-modal="true"
    [search input]  ← filters items by name/hint/group
    [listbox]
      [group label]
        [item] [name] [hint] [kbd]
        ...
```

## Keyboard behavior

| Key | Effect |
|-----|--------|
| `Arrow Down / Up` | Navigate items |
| `Enter` | Execute highlighted item's action, closes overlay |
| `Escape` | Close without action |
| `Tab` / `Shift+Tab` | Focus cycles within overlay (focus trap) |
| Any character | Filters the list via the search input |

## Examples

export const CommandPalette = () => {
  const [open, setOpen] = useState(false);

  const items = [
    { group: 'Sandbox', name: 'Create sandbox', hint: 'Start a new environment', action: () => { toast_info('Create sandbox'); setOpen(false); } },
    { group: 'Sandbox', name: 'Clone sandbox', hint: 'Duplicate current environment', action: () => setOpen(false) },
    { group: 'Sandbox', name: 'Delete sandbox', hint: 'Permanently destroy', action: () => setOpen(false) },
    { group: 'Navigation', name: 'Go to sandboxes', action: () => setOpen(false) },
    { group: 'Navigation', name: 'Go to tenants', action: () => setOpen(false) },
    { group: 'Navigation', name: 'Go to audit log', action: () => setOpen(false) },
    { group: 'Account', name: 'Settings', kbd: '⌘,', action: () => setOpen(false) },
    { group: 'Account', name: 'Sign out', action: () => setOpen(false) },
  ];

  return (
    <div style={{ padding: 16 }}>
      <Button variant="ghost" kbd="⌘K" onClick={() => setOpen(true)}>Open palette</Button>
      <CmdKOverlay
        open={open}
        onClose={() => setOpen(false)}
        items={items}
        placeholder="Search actions…"
      />
    </div>
  );
};

## Implementation note

CmdKOverlay is a **controlled** component — you manage `open` state and wire up the `⌘K` / `Ctrl+K` keydown listener yourself. A typical setup:

```tsx
useEffect(() => {
  const handler = (e: KeyboardEvent) => {
    if ((e.metaKey || e.ctrlKey) && e.key === 'k') {
      e.preventDefault();
      setOpen(true);
    }
  };
  window.addEventListener('keydown', handler);
  return () => window.removeEventListener('keydown', handler);
}, []);
```

## Accessibility checklist

- `role="dialog"` and `aria-modal="true"` on the panel.
- Search input has `role="combobox"` and `aria-controls` pointing to the listbox.
- Active item tracked with `aria-activedescendant`.
- Focus trap keeps Tab within the overlay.
- Escape closes and returns focus to the trigger.
