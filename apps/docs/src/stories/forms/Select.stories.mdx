# Select

Native `<select>` element with custom arrow styling and design-system sizing. Ideal for short, static option lists (≤15 items) where a native dropdown is appropriate.

## When to use

- Choosing one option from a short, known list: region, environment, tier, policy.
- When native mobile keyboard/UX for `<select>` is desirable.
- As a base control inside `FormField` for labeled selection.

## When NOT to use

- Lists longer than ~15 items — prefer `Combobox` (searchable).
- Multi-selection — use `MultiSelect`.
- When you need option grouping with descriptions — use `RadioGroup` with `variant="card"`.

## Anatomy

Renders a single `<select>` element. Children are native `<option>` and `<optgroup>` elements.

## Keyboard behavior

Inherits native `<select>` keyboard behavior:

| Key | Effect |
|-----|--------|
| `Space` | Opens the dropdown |
| `Arrow Up/Down` | Navigates options |
| `Enter` | Confirms selection |
| `Escape` | Closes without change |

## Examples

### Default

export const Default = () => {
  const [val, setVal] = useState('us-east-1');
  return (
    <div style={{ padding: 16, maxWidth: 260 }}>
      <Select value={val} onChange={e => setVal(e.target.value)}>
        <option value="us-east-1">us-east-1</option>
        <option value="us-west-2">us-west-2</option>
        <option value="eu-west-1">eu-west-1</option>
        <option value="ap-southeast-1">ap-southeast-1</option>
      </Select>
    </div>
  );
};

## Accessibility checklist

- Always associate with a label via `<label htmlFor>` or wrap in `FormField`.
- `invalid` sets `aria-invalid="true"` on the select element.
- Disabled options get native `disabled` attribute — do not rely on CSS alone.
