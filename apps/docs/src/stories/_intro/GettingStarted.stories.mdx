# @talon-sandbox/react

A CSS-token-driven React component library for Talon Sandbox. Components emit semantic class names (`tln-*`) and delegate all visual decisions to design tokens — no Tailwind required.

## Installation

```bash
pnpm add @talon-sandbox/react @talon-sandbox/tokens
```

## Quick start

```tsx
// 1. Import the stylesheet (once, at your app root)
import '@talon-sandbox/react/styles';

// 2. Set theme/mode/density on <html> (or any ancestor)
//    data-theme="ink" data-mode="dark" data-density="standard"

// 3. Use components
import { Button, Input } from '@talon-sandbox/react';

export function MyForm() {
  return (
    <form>
      <Input placeholder="Sandbox name" />
      <Button variant="primary">Create</Button>
    </form>
  );
}
```

## Theming

Theme is controlled by `data-*` attributes on a container element (usually `<html>`):

| Attribute | Values | Default |
|-----------|--------|---------|
| `data-theme` | `ink` `onyx` `pewter` `iron` `phosphor` `indigo` `violet` `sky` `teal` | `ink` |
| `data-mode` | `dark` `light` | `dark` |
| `data-density` | `compact` `standard` `relaxed` | `standard` |
| `data-font` | `geist` `plex` `jetbrains` `system` | `geist` |
| `data-lang` | `en` `zh` | `en` |

Use the **Tweaks** panel (top-right corner of this docs site) to switch theme, mode, and density live.

## Package structure

```
@talon-sandbox/react   — React components + CSS classes
@talon-sandbox/tokens  — Raw design tokens (CSS vars, JSON, Tailwind preset)
```

## CSS-only approach

All styling is in `@talon-sandbox/react/styles` (a single compiled CSS file). Components never import Tailwind or emit utility classes — they emit stable `tln-*` BEM-ish class names. This means:

- Works in any CSS environment (Tailwind project, vanilla CSS, CSS Modules)
- No purging surprises — the stylesheet is self-contained
- Overriding is predictable: target the `tln-*` class

## TypeScript

All components ship full TypeScript types. Props interfaces are exported alongside each component:

```tsx
import type { ButtonProps, ButtonVariant } from '@talon-sandbox/react';
```
