# Drawer

Side sheet (right or left) with focus trap, backdrop click, and Escape-to-close. Renders into a portal at `document.body`.

## When to use vs Dialog

| | Dialog | Drawer |
|--|--------|--------|
| **Space** | Fixed-width centered modal | Full-height side panel (560 px default, customizable) |
| **Content** | Short confirmations, small forms, info cards | Multi-field forms, detail views, edit panels |
| **Best for** | "Are you sure?", rename, view stats | Create sandbox, edit tenant settings, view resource detail |

Use Drawer when the user needs to interact with a form while still having context about the underlying page. Use Dialog for focused decisions that block everything else.

## Anatomy

```
[backdrop — click to close]
[.tln-drawer side=right|left]
  [.tln-drawer-head]
    [.tln-drawer-title]  ← title prop
    [close button]
  [.tln-drawer-body]     ← children prop
```

## Keyboard behavior

| Key | Effect |
|-----|--------|
| `Escape` | Closes the drawer |
| `Tab` | Cycles through focusable elements inside (focus trap) |
| `Shift+Tab` | Cycles backwards |

## Gotchas

- `width` can be a number (pixels) or CSS string (`'40vw'`, `'min(560px, 90vw)'`).
- On mobile viewports, drawers are full-width by default via CSS — the `width` prop is a max-width guideline.
- Like Dialog, the Drawer does not manage open state internally — you must flip your state flag in `onClose`.

## Accessibility checklist

- `role="dialog"` and `aria-modal="true"` are set automatically.
- `aria-labelledby` is wired to `title` when provided.
- Focus trap prevents Tab from leaving the drawer while open.
- Escape closes (calls `onClose`).
- Return focus to the trigger button after close — caller responsibility.
